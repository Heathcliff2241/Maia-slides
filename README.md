# Maia Bunny's Flashcards 🐰

Upload a PDF, get a deck of flashcards + a 5-question quiz, generated by Gemini.
Spaced repetition (Leitner-style: Again / Good / Easy) tracks what's due for review.
Decks are saved in the browser (localStorage) — no login, no database needed.

## 1. Get a Gemini API key

Free tier is fine for this. Go to https://aistudio.google.com/apikey, create a key.

## 2. Run it locally

```bash
npm install
cp .env.local.example .env.local
# paste your key into .env.local
npm run dev
```

Open http://localhost:3000.

## 3. Make it live (Vercel — matches your usual stack)

```bash
git init
git add .
git commit -m "maia flashcards"
```

Push to a new GitHub repo, then:

1. Go to https://vercel.com/new and import the repo.
2. In the project's Environment Variables, add:
   - `GEMINI_API_KEY` = your key
   - (optional) `GEMINI_MODEL` = `gemini-2.0-flash` (default) or another Gemini model
3. Deploy. That's it — you get a live URL to send her.

## How it works

- `app/api/generate/route.js` — receives the PDF, extracts text with `pdf-parse`,
  sends it to Gemini asking for JSON back (title + flashcards + quiz).
- `lib/spacedRepetition.js` — a small 5-box Leitner system. "Again" resets a card
  to box 1 (due again in ~10 min, same session); "Good"/"Easy" push it further out
  (up to ~30 days).
- `lib/storage.js` — all decks + review progress live in `localStorage`, keyed per
  browser. Good enough for one or two people sharing a link on their own devices.
- Everything else (`components/`) is plain React — no state library, easy to read
  and extend.

## Customizing further

- Her name and the "Maia bunny" copy are in `app/page.js` (`GREETING_NAME`) and
  scattered through `StudyView.js` / `globals.css` — search for "Maia" to find every spot.
- Colors are CSS variables at the top of `app/globals.css` (`--rose`, `--blush`, etc.)
  if you want to shift the palette.
- Card counts, quiz length, and the generation prompt live in `app/api/generate/route.js`.

## Known limits (worth knowing before you rely on it)

- Scanned/image-only PDFs won't extract text — `pdf-parse` needs a real text layer.
- Very long PDFs get truncated to the first ~18,000 characters sent to Gemini, to keep
  cost and latency sane. Bump `MAX_CHARS` in the API route if you want more.
- Decks live in the browser only — clearing browser data wipes them. If you want
  decks to sync across her phone and laptop, the natural next step is swapping
  `lib/storage.js` for Supabase (which you already use elsewhere).
